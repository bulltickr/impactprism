⌬

Checks selected controls

Compares supported manifests, lockfiles, and source imports for drift, undeclared use, transitive use, scope, and lockfile mismatches. Coverage varies by ecosystem and available files.

▣

Evidence for review

Produces Markdown and JSON with observed inputs, findings, statuses, rationale, and configured reference mappings. Findings require review, and evidence may be incomplete.

⇄

No hosted service required

One local scan needs no account, API key, or vulnerability database. Installation and managed CI bootstrap may need package artifacts; scan execution never sends your source anywhere.

From inventory to preflight

Many SBOM tools inventory what you declared. A manifest-only inventory can miss what you never declared — a component your source imports that is absent from the supported manifest or lockfile, or a declared component that is not observed in the scanned source. ImpactPrism performs bounded dependency-integrity checks so reviewers can investigate those mismatches before release.

Capability Typical SBOM tool ImpactPrism
Dependency inventory Lists declared components Cross-checks manifest + lockfile + source imports
Drift detection No Yes — declared-but-never-imported, core feature
Evidence trail No Yes — review-oriented findings, statuses, rationale, Markdown & JSON
Actionable findings CVEs on declared deps Selected drift, undeclared, transitive, scope & lockfile checks
